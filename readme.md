# Antispam bot

Telegram-бот удаляет пересланные публикации из заблокированных каналов. Списки
хранятся в SQLite отдельно для каждого чата.

Если отдельное слово `топор` встречается в тексте сообщения или подписи к медиа,
бот отвечает на сообщение: `ХА! ЕГОР ЛОХ, НЕ ПРОЙДЕШЬ!`, а исходное сообщение
удаляет. Регистр букв не важен.

## Запуск через Docker Compose

1. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
2. Добавьте бота в группу администратором с правом удаления сообщений.
3. Запустите бота:

```shell
docker compose up -d --build
```

База данных сохраняется в `data/bot.sqlite3` на хосте.

## Локальный запуск через uv

```shell
uv sync
uv run python main.py
```

## Команды

Доступны всем участникам:

- `/myid` — показать ваш Telegram ID.
- `/id` (также `/chatid`) — показать ID чата и пользователя.

Доступны администраторам текущего чата и пользователям из `ADMIN_USER_IDS`:

- `/users` — показать известные боту ID участников текущего чата.
- `/block <channel_id|@username>` — добавить канал в блок-лист текущего чата.
- `/unblock <channel_id|@username>` — удалить канал из блок-листа текущего
  чата.
- `/blocklist` — показать блок-лист текущего чата.
- `/banuser <user_id>` (также `/ban`) — удалять пересылки этого пользователя
  из каналов в блок-листе.
- `/unbanuser <user_id>` (также `/unban`) — снять фильтр с пользователя.
- `/banlist` — показать пользователей, для которых включён фильтр.

Примеры:

```text
/block -1001234567890
/block @example
/banuser 123456789
/unban 123456789
```

Команды `/block` и `/unblock` без аргумента можно отправить ответом на
пересланное сообщение из нужного канала. Аналогично `/banuser`, `/ban`,
`/unbanuser` и `/unban` можно отправить ответом на сообщение пользователя.
В SQLite вместе с ID сохраняется название канала. Для старых записей бот
запрашивает название через Telegram Bot API при запуске или вызове `/blocklist`.
Приватный канал без доступа для бота может остаться без названия.

Несколько ID в `ADMIN_USER_IDS` перечисляются через запятую.

Telegram Bot API не позволяет получить полный список обычных участников группы.
Поэтому `/users` показывает администраторов и пользователей, которых бот уже
видел в сообщениях или событиях входа. Список пополняется автоматически и
хранится в SQLite.

До первого вызова `/banuser` блок-лист каналов действует для всех участников,
как и раньше. Первый `/banuser` включает адресный режим в текущем чате: после
этого пересылки из заблокированных каналов удаляются только у пользователей из
`/banlist`. Режим сохраняется после перезапуска, даже если список затем станет
пустым.

При первом обращении к новому чату значения `BLOCKED_CHANNEL_IDS` из `.env`
однократно копируются в его SQLite-блок-лист. Последующие изменения выполняются
командами и сохраняются после перезапуска.
